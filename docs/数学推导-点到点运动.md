# 从零点到指定点的完整数学推导

本文推导虚拟六轴机械臂"从零点运动到指定点"的完整数学过程：
**逆运动学（求目标关节角）→ 多轴同步轨迹规划（求各轴运动曲线）→
脉冲换算（驱动步进电机）**。所有公式均与代码实现
（`arm_model.py` / `ik_solver.py` / `trajectory.py`）一一对应。

约定：关节角向量 $q = [q_1,\dots,q_6]^T$（度），末端位姿为 4×4 齐次矩阵 $T$。

---

## 1. 运动学模型（广义 DH）

机械臂尺寸取自稚辉君 Dummy-Robot 固件（单位 m）：

| 符号 | 数值 | 含义 |
|---|---|---|
| $L_{BASE}$ | 0.109 | 基座高度（J1 → J2 垂直距离） |
| $D_{BASE}$ | 0.035 | 基座水平偏移（J1 轴 → J2 轴） |
| $L_{ARM}$ | 0.146 | 大臂长度（J2 轴 → J3 轴） |
| $L_{FOREARM}$ | 0.115 | 小臂长度（J3 轴 → J5 轴交点） |
| $D_{ELBOW}$ | 0.052 | 肘部横向偏移（J3 轴 → J4 轴） |
| $L_{WRIST}$ | 0.072 | 腕部/工具长度（J5 轴交点 → 工具末端） |

固件的 FK 不是教科书式标准 DH：连杆平移向量含标准 DH（平移须落在
连杆 $x$-$z$ 平面内）无法表达的 $y$ 向分量，因此采用**旋转 DH + 连杆
平移向量**混合模型——每个关节的变换为：

$$A_i(q_i) = \mathrm{Rot}_Z(q_i + \theta_i^{off}) \cdot \mathrm{Trans}(t_i) \cdot \mathrm{Rot}_X(\alpha_i)$$

即旋转部分 $\mathrm{Rot}_Z(\cdot)\mathrm{Rot}_X(\cdot)$、平移部分 $t_i$
独立给出（$t_i$ 是该连杆坐标系内的常值向量）。六个关节的参数表：

| 关节 | $\theta^{off}$ (°) | $\alpha$ (°) | $t = [t_x, t_y, t_z]$ (m) |
|---|---|---|---|
| J1 基座 | 0 | −90 | $[0,\ 0,\ 0]$ |
| J2 大臂 | −90 | 0 | $[0.035,\ -0.109,\ 0]$ |
| J3 小臂 | 90 | 90 | $[0.146,\ 0,\ 0]$ |
| J4 腕 1 | 0 | −90 | $[-0.052,\ 0,\ 0.115]$ |
| J5 腕 2 | 0 | 90 | $[0,\ 0,\ 0]$ |
| J6 腕 3 | 0 | 0 | $[0,\ 0,\ 0.072]$ |

关节限位（度）：J1 ±170，J2 [−73, 90]，J3 [35, 180]，J4 ±180，J5 ±120，J6 ±720。

## 2. 正运动学（FK）

连杆变换依次右乘，末端位姿为：

$$T_0^6(q) = A_1(q_1)\,A_2(q_2)\,A_3(q_3)\,A_4(q_4)\,A_5(q_5)\,A_6(q_6) = \begin{bmatrix} R & p \\ 0 & 1 \end{bmatrix}$$

其中 $p \in \mathbb{R}^3$ 是工具末端位置，$R \in SO(3)$ 是姿态。
中途各 $T_0^k$ 的平移分量即各关节球的位置（用于 3D 渲染）。

**零点验证**：取零点 $q_0 = [0, 0, 90, 0, 0, 0]^T$（大臂竖直、小臂水平），
FK 得末端 $p = (0.222,\ 0,\ 0.307)$ m——位于过基座轴线的竖直平面内，
与机械结构一致。

## 3. 逆运动学：目标点 → 目标关节角 $q^\*$

指定点以位姿给出 $T_{target}$（位置 + ZYX 欧拉角
$R = R_z(yaw)R_y(pitch)R_x(roll)$）。六轴臂 IK 有多解且本模型非标准 DH，
解析解（Pieper 法）推导繁琐，工程上采用**阻尼最小二乘（Levenberg–Marquardt）
数值迭代**，稳定且天然带限位约束。

### 3.1 位姿误差向量

定义末端当前位姿与目标的误差旋量 $e = [e_p;\ e_o] \in \mathbb{R}^6$（基系表达）：

- **位置误差**：$e_p = p_{target} - p(q)$
- **姿态误差**（旋转矢量，即旋转矩阵对数）：令
  $R_{err} = R_{target}\,R(q)^T$，设其转角为 $\theta$、转轴为 $k$，则

$$e_o = \log(R_{err}) = \theta\, k$$

实际计算避免显式求轴角：取 $R_{err}$ 的反对称部分
$v = \mathrm{vee}(R_{err} - R_{err}^T)/2 = \sin\theta \cdot k$，
及 $\cos\theta = \big(\mathrm{tr}(R_{err}) - 1\big)/2$，于是

$$e_o = \frac{\arccos(\cos\theta)}{\sin\theta}\, v$$

小角度时退化为 $e_o \approx v$（一阶正确）。

### 3.2 几何雅可比

各关节均为旋转关节。设第 $i$ 个关节轴单位向量为 $z_i$（基系）、轴线上一点
$o_i$、末端位置 $o_n$，则

$$J_i = \begin{bmatrix} z_i \times (o_n - o_i) \\ z_i \end{bmatrix}, \qquad J = [J_1 \cdots J_6] \in \mathbb{R}^{6\times 6}$$

满足 $\begin{bmatrix} v \\ \omega \end{bmatrix} = J\,\dot q$。
（注：本模型中间坐标系原点不都落在下一关节轴线上，故 $o_i$ 取
$T_0^{i+1}$ 的原点，见 `arm_model.geometric_jacobian`。）

### 3.3 LM 迭代

求解加权最小二乘问题 $\min_q \tfrac{1}{2}\lVert W e(q) \rVert^2$，
权重 $W$ 把位置误差（量级 0.1 m）与姿态误差（无量纲）归一到同一尺度。
LM 更新方向：

$$\big(J^T W^2 J + \lambda \operatorname{diag}(J^T W^2 J)\big)\, h = J^T W^2 e$$

- $\lambda$ 为阻尼系数：**奇异附近** $J^T J$ 病态，$\lambda$ 项使求逆稳定
  （这正是"阻尼最小二乘"名称的来源）；
- 采用 **Nielsen 增益比**信赖域策略：设实际下降与预测下降之比为
  $\rho$，$\rho > 0$ 则接受步长并缩小 $\lambda$（扩大信赖域），
  否则拒绝并增大 $\lambda$（缩小信赖域）。

### 3.4 工程细节

1. **步长限制**：单步 $\lVert h \rVert_\infty \le 45°$，防大误差下线性化失效；
2. **限位惩罚**：距限位 1° 内加入二次惩罚梯度，把解拉回可行域；
3. **多初值重启**：主初值（取当前关节角，保证最小转角）不收敛时，
   按 $20°/45°/90°/135°$ 递增幅度高斯扰动 + 全局均匀采样重启；
4. **收敛判据**：$\max_i \lvert (We)_i \rvert < 5\times 10^{-4}$
   （位置 ≈ 0.05 mm 量级）。

## 4. 轨迹规划：$q_0 \to q^\*$ 的多轴同步运动

已知起点 $q_0$（零点）、终点 $q^\*$，各轴速度/加速度上限
$v_{max}, a_{max}$。目标是生成固定周期采样的角度序列 $q(t_k)$。

核心思想（与 Dummy-Robot 固件一致）：**找出"最难走的轴"，以它的
最短运动时间作为全轨迹的公共时间，其余轴按比例缩放自己的速度**，
从而 6 轴同时到达、轨迹同步。

### 4.1 单轴时间最优（梯形速度曲线）

某轴需转过 $\Delta = |q_i^\* - q_{0i}|$。设加速时间 $t_a$、峰值速度
$v_p = a_{max} t_a$。

**情形 A：能达到最高速**（$\Delta \ge 2 d_{acc}$，其中加速段位移
$d_{acc} = \tfrac{1}{2} a_{max} t_a^2$）：

$$T = 2 t_a + \frac{\Delta - 2 d_{acc}}{v_{max}}, \qquad t_a = \frac{v_{max}}{a_{max}}$$

**情形 B：三角形曲线**（行程短，没加速到 $v_{max}$ 就要减速）：
由 $\Delta = 2 \cdot \tfrac{1}{2} a_{max} t_a^2$ 得

$$t_a = \sqrt{\frac{\Delta}{a_{max}}}, \qquad v_p = a_{max} t_a, \qquad T = 2 t_a$$

### 4.2 S 曲线（余弦加速度，冲击更小）

梯形曲线的加速度突变会产生冲击（jerk 无穷大）。S 曲线令加速度按
余弦渐变：

$$a(t) = \frac{a_{pk}}{2}\left(1 - \cos\frac{2\pi t}{t_a}\right)$$

积分得速度为正弦形加速段。注意**平均加速度**为 $a_{pk}/2$，因此：

- 加速到 $v_{max}$ 的时间 $t_a = \dfrac{2 v_{max}}{a_{max}}$（是梯形的 2 倍）；
- 三角形情形：$\Delta = 2\int_0^{t_a} v\,dt = \dfrac{a_{max} t_a^2}{4}
  \Rightarrow t_a = \sqrt{\dfrac{2\Delta}{a_{max}}}$，$v_p = \dfrac{a_{max} t_a}{2}$。

### 4.3 多轴时间同步

对每个轴用 4.1/4.2 算出其**各自最短**时间 $T_i$，取

$$T = \max_i T_i$$

其余轴不能提前到达，将其峰值速度按比例压缩：

$$v_{pk,i} = v_{best,i} \cdot \frac{T_i}{T}$$

这样所有轴的加速/匀速/减速段时刻完全一致（时间比 = 速度比的倒数），
同时启停、同时到达。这是将来 6 个步进电机"同一段时间内发完各自
脉冲数"的脉冲时序基础。

### 4.4 采样

时间轴 $t_k = k\,dt$（$dt = 0.02$ s），每轴代入速度曲线公式得
$\dot q_i(t_k)$，角度由**累积梯形积分**求得：

$$q_i(t_{k+1}) = q_i(t_k) + \frac{\dot q_i(t_k) + \dot q_i(t_{k+1})}{2}\, dt$$

并强制末帧 $q(T) = q^\*$ 精确对齐。

## 5. 完整算例：零点 → 指定点 $(0.20,\ 0,\ 0.15)$ m，姿态 $(180°, 0, 0)$

**第 1 步（IK）**：以零点 $q_0$ 为初值迭代 6 次收敛：

$$q^\* = [0,\ 8.17,\ 161.24,\ 0,\ -79.37,\ 0]^T \ \text{(°)}, \qquad \|e_p\| = 4\times 10^{-7}\ \text{m}$$

关节位移 $\Delta q = [0,\ +8.17,\ +71.24,\ 0,\ -79.37,\ 0]^T$ °
（目标在 $x$-$z$ 平面内，故 J1/J4/J6 不动）。

**第 2 步（单轴时间）**（$v_{max} = [120,90,90,180,180,360]$ °/s，
$a_{max} = [300,240,240,540,540,900]$ °/s²）：

| 轴 | $\Delta q$ (°) | 梯形 $T_i$ (s) | S 曲线 $T_i$ (s) | 瓶颈？ |
|---|---|---|---|---|
| J2 | +8.17 | 0.369 | 0.522 | |
| J3 | +71.24 | **1.167** | **1.542** | ✅ 最难走的轴 |
| J5 | −79.37 | 0.774 | 1.084 | |

**第 3 步（同步后）**：

| 曲线 | 公共时间 $T$ | 帧数 | 各轴峰值速度 (°/s) |
|---|---|---|---|
| 梯形 | 1.167 s | 60 | $[0, 14.0, 90.0, 0, 119.5, 0]$ |
| S 曲线 | 1.542 s | 79 | $[0, 10.6, 90.0, 0, 103.0, 0]$ |

例如 J2 按比例压缩：梯形 $44.27 \times 0.369/1.167 = 14.0$ °/s。
S 曲线时间更长（平均加速度减半）但速度光滑、无冲击。

## 6. 到步进电机的映射

采样序列 $q(t_k)$ 换算为每个电机的**脉冲数与方向**：

$$N_i(k) = \big(q_i(t_k) - q_i(0)\big) \times P_{deg}, \qquad DIR_i = \mathrm{sign}\big(\dot q_i\big)$$

其中 $P_{deg} = 100$ 脉冲/°（虚拟细分，见网页波形区）。
相邻两帧脉冲增量 $\Delta N_i(k) = N_i(k) - N_i(k-1)$ 决定该轴在
$dt$ 内应发的 STEP 数——多轴同步保证了所有轴在相同的 $T$ 内
发完各自的脉冲，电机按帧执行即复现整条轨迹。
